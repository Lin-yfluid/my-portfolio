# 从 Blender 到 Unity：民族文物虚拟展馆的完整制作流程

做《古韵新"镜"》那段时间，我最大的收获不是学会了某个软件的操作，而是摸清了一条资产从建模到能在引擎里跑起来的完整链路。这篇把流程完整复盘一遍。

## 一、先定规范，再动手建模

新手最容易犯的错是拿到参考图就直接开建，建到一半发现比例不对、单位不对，全部返工。我在广西壮锦博物馆那个项目里吃过这个亏，后来形成固定动作：

| 规范项 | 设定 | 为什么 |
|---|---|---|
| 单位 | 统一用米，1 单位 = 1 m | 导入 Unity 后不会出现"模型巨大/微缩" |
| 朝向 | 正面朝 -Z | Unity 相机默认看向 +Z |
| 原点 | 物体原点在底部中心 | 摆放到展台时不用反复调高度 |
| 变换 | 导出前应用全部变换 | 避免缩放错乱 |
| 命名 | `展品_编号_版本` | 后期替换不混乱 |

## 二、建模与纹样还原

民族饰品的难点在纹样。直播式的"每个展品单独雕"效率极低，我的做法是先提取纹样的**构成规律**——对称轴、重复单元、配色层级——再把它做成可复用的贴图与建模模板。

```text
纹样分析 → 提取重复单元 → 制作无缝贴图
        → 建基础体块 → UV 展开 → 贴图投射
        → 细节雕刻（少量）→ 烘法线
```

关键判断：**能靠贴图表达的细节就不要用几何体表达**。一个纹样的凹凸，用几何做要几万面，用贴图只要一张 1024 的 normal map。

## 三、材质与布光

展厅氛围很大程度取决于光。我踩过的坑是把材质调到"单看很好看"，进场景后发现整体发灰。原因是场景里有大量漫反射表面，环境光不足。

调整思路：

1. 先定环境光基调（展厅用偏暖、稍暗的环境色）
2. 再打主光，控制在 2–3 个方向
3. 最后补展品单独的打光，让视觉焦点落在展品上

材质上统一走 PBR 流程：颜色、粗糙度、金属度三个通道对齐实物，避免"塑料感"。

## 四、导入 Unity 与交互

资产进引擎后才是真正的工作量。我负责的交互主要有三类：

- **漫游**：CharacterController + 胶囊碰撞体，移动与转向分离处理
- **展品点选**：射线检测 → 命中展品 → 触发讲解面板
- **镜头聚焦**：点选后相机平滑移动到展品前，退出时归位

```csharp
// 展品点选的核心逻辑（简化版）
Ray ray = Camera.main.ScreenPointToRay(Input.mousePosition);
if (Physics.Raycast(ray, out RaycastHit hit, 5f)) {
    var exhibit = hit.collider.GetComponent<ExhibitItem>();
    if (exhibit != null) FocusOn(exhibit);   // 镜头聚焦 + 弹出讲解
}
```

镜头聚焦必须用插值而不是直接赋值，否则会有强烈的"瞬移"感，晕得厉害。

## 五、性能收尾

展馆类项目最容易忽略的是性能。我做的三件事：

1. **减面**：展品控制在合理面数内，细节转移给法线贴图
2. **贴图压缩**：统一尺寸阶梯，非重点展品降一档
3. **合批**：同材质的静态展台合并，减少 Draw Call

## 六、复盘

这条链路走通之后，我再看任何虚拟场景项目都能快速估出工作量：建模占 50%，材质布光 20%，交互 20%，优化 10%。项目能拿省级二等奖，靠的不是某一个环节特别亮眼，而是每个环节都没掉链子。
