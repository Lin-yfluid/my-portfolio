# Blender 导入 Unity 的 7 个高频坑

做虚拟展馆的那段时间，我在"模型进引擎"这一步浪费的时间几乎和建模一样多。这篇把踩过的坑按遇到频率排个序，附排查方法，希望能帮后来的人省点时间。

## 1. 模型巨大或微缩到看不见

**现象**：导入后模型要么塞满场景，要么小得像个点。

**原因**：Blender 默认单位和 Unity 的单位不一致，或导出时缩放没应用。

**解决**：Blender 里场景单位设为米，导出前 `Ctrl+A` → 应用缩放与旋转。

## 2. 法线反转，模型里面朝外

**现象**：模型表面出现奇怪的黑斑，或者从里面能看到外面。

**原因**：建模时法线方向反了，或者非流形几何。

**排查**：Blender 里打开 `Face Orientation` 叠加显示，蓝色为正面、红色为反面；选中反的面 `Shift+N` 重算法线。

## 3. 材质丢失变成纯白

**现象**：进 Unity 后所有模型都是白模。

**原因**：Blender 的材质节点没被正确导出，或贴图路径丢失。

**解决**：导出 FBX 时勾选嵌入纹理，或者把贴图文件和模型放同一目录再导入；Unity 侧检查材质的 Albedo 贴图槽是否为空。

## 4. 贴图不显示 / 显示成粉色

**现象**：材质在 Unity 里是紫红色。

**原因**：贴图没被识别为 Texture 类型，或路径引用断了。

**解决**：检查 Inspector 里的贴图导入设置，确认 Texture Type 正确；重新指定贴图。

## 5. UV 错乱，贴图皱在一起

**现象**：贴图被拉伸、重叠、错位。

**原因**：UV 没展开，或者多个物体共用一份 UV 但尺寸不同。

**解决**：逐个物体检查 UV 展开（`U` → 智能 UV 投射后手动微调）；不同展品不要共用同一份 UV 布局。

## 6. 模型面数过高，场景卡顿

**现象**：编辑器里就掉帧，打包后更明显。

**原因**：雕刻细节全部保留为几何体。

**解决**：减面（Decimate）→ 烘法线贴图 → 用渲染好的贴图替换原始细节。面数通常能降一个数量级。

## 7. 光照异常，场景一片死黑

**现象**：导进来的模型不吃光，或者亮得发白。

**原因**：光照贴图设置、材质自发光、或 Unity 里没重新烘焙。

**排查**：
- 检查材质是否误勾了 Emission
- 确认场景有 Directional Light
- 静态物体重新 Bake 光照

## 我的固定检查清单

导入一个新模型后，我按这个顺序过一遍，基本不会漏：

```
□ 缩放是否为 1,1,1
□ 朝向是否正确
□ Face Orientation 是否全蓝
□ 材质球是否都有贴图
□ 贴图是否为 Texture 类型
□ UV 是否展开
□ 面数是否在预算内
```

**一句话总结**：这些坑本质上都是"两个软件之间的契约没有对齐"。把规范定下来，坑就变成可以批量避免的流程问题。
